Instalar um modelo

No terminal do servidor, dentro da pasta do projeto:

docker compose --profile setup run --rm model-setup list
docker compose --profile setup run --rm model-setup plan qwen-1.7b
docker compose --profile setup run --rm model-setup install qwen-1.7b --accept-license

O plano informa tamanho, licença e revisão. Instale também um modelo Whisper para transcrição. Consulte o MANUAL.md para instalação offline e backup.

Estado desta versão

Núcleo, personagens, fila, VoiceScript básico, adaptadores de clonagem e transcrição, e dublagem por SRT.

Conversão direta, tradução automática, separação de ambiente, emoções e treinamento permanecem pendentes. A qualidade dos modelos e o consumo no A10 precisam de avaliação local. Equivalência ao ElevenLabs não foi demonstrada.
